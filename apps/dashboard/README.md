# Attendrix Vite dashboard

Canonical React + TypeScript + Vite dashboard for the API contract in ../../docs/API_CONTRACT.md. Sign-in requires a configured backend; there are no local demo accounts or fabricated data fallbacks.

## Run

    Copy-Item .env.example .env
    npm ci
    npm run dev

Configure VITE_API_BASE_URL in the local environment. The client obtains a one-time WebSocket ticket, then connects over ws/wss derived from the API origin. Realtime messages trigger REST refreshes. CSV is generated by the backend; print output uses the backend's report HTML.

The dashboard provides role-selected login, timed lecturer sessions, review queue, manual roll call, history/report export, and student history/notifications. Students are directed to the mobile camera workflow to submit a sweep. A browser end-to-end flow against a configured Supabase environment has not yet been verified.
